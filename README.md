A Wi-Fi network name that tells a whole breakup story in 32 characters: "Ex took the dog. I kept the WiFi" — 32 characters exactly. She got the dog in the split; he kept the WiFi. `main.py` validates the line (1–32 characters, valid UTF-8, not whitespace-only) and writes it, with no trailing newline, to `entry.txt`.

## Run it

Requires Python 3.

```sh
MAKEFUN_OUTPUT_DIR=./output python3 main.py
```
